# pairwise-audioeq

## 题面（可直接粘贴）

多段均衡器。约束：0 dB 原样；必须实现二阶 biquad 低架/高架滤波并维护滤波状态，跨缓冲区处理与整段一致；频段响应单调且无爆音（相邻样本差有上界）；100 万样本不超过 300 ms；状态可重置；非法频段/增益要给出可区分的错误。验收：python -m pytest tests -q -k eq。改动限 2 到 3 个文件，增量构建加测试不超过 30 秒。不得改动既有测试与既有行为。交付给命令、输出、耗时三行自测证据。

## 边界要求（评审侧隐藏用例判分）

- 10 万样本耗时
- 并发
- 非有限样本
- 频段边界
- 增益上限

## 运行方式

```bash
python -m pytest tests -q
```

初始 15 failed。可见测试只覆盖主功能（3 分线）。
